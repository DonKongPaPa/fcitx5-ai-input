# vision 子智能体中性测量探针（surface-test 根因分析用）

## 纪律（防暗示——所有条目同等强制）

- **只问事实，不问判断**：禁止出现「偏移/应该/期望/是否准确/我们的/
  被测/bug」等结论性词汇
- **不画期望**：annotate.py 只画标尺+线框+caret 虚线；不画箭头、期望框、
  高亮；不标注哪个窗是测量对象
- **单元素单问**：一次只问一个元素的坐标
- **裁剪区无提示边框**
- **固定模板**：措辞不得漂移；模板与标注器分离维护
- **vision 永远是第二测量者**：程序差分 bbox 是真值；vision 结果与真值
  差 >8px 标「低置信」

## 提问模板（逐字使用）

```
图中有带刻度标尺（顶部与左侧，单位像素）与若干白色编号线框（R1…Rn），
另有一个黄色虚线框（标签 caret）。请按标尺读数，输出以下三组纯数值：

1. 图中唯一的深色圆角面板元素的外接矩形：{x, y, w, h}
2. 标签为 caret 的黄色虚线框矩形：{x, y, w, h}
3. 两者中心点的差值：{dx, dy}

仅返回 JSON：
{"bbox": {"x":..,"y":..,"w":..,"h":..},
 "caret": {"x":..,"y":..,"w":..,"h":..},
 "delta": {"dx":..,"dy":..}}
```

变体（classicui 测量——浅色面板）只改第 1 条：

```
1. 图中唯一的浅色（白底）候选列表面板元素的外接矩形：{x, y, w, h}
```

## 校准流程（每轮测量前，基准场景）

1. 用 S1（左列基准，两引擎位置应正确）先跑：PIL 差分 bbox = 程序真值
2. vision 读数与真值差 ≤8px → 本轮结果标「高置信」；否则「低置信」双列
3. 报告中程序测量与 vision 测量并列呈现；不一致时高亮，以程序真值为准
